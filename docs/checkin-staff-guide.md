# Check-in staff guide

*The scanner ships in Phase 2. The rule below is agreed now and applies on the day.*

## The one rule for offline scanning

> **While a scanner is offline, only one scanner may work each entrance.**

The scanner keeps working if venue internet drops. It checks tickets against an encrypted list downloaded before doors open. But two scanners that are **both** offline cannot see each other's scans, so the same ticket could be admitted twice and the duplicate only discovered when they reconnect.

When a scanner goes offline it shows a **warning banner** for as long as it stays offline. When you see the banner:

1. Tell your entrance lead.
2. Make sure yours is the only scanner admitting people at this entrance.
3. Keep scanning normally. Your scans sync automatically when the connection returns.

## Results

Every result shows a symbol **and** a word. Never rely on the colour alone.

| Screen | Means | What to do |
|---|---|---|
| ✓ **VALID** | Real ticket, not used yet | Check the name, tap **Admit** |
| ! **ALREADY CHECKED IN** | Scanned before, with the time shown | Don't admit. Send to the help desk |
| ✕ **INVALID** | Fake, cancelled or refunded ticket | Don't admit. Send to the help desk |
